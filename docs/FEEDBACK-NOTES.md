# ご意見メモ

## 使い方

- ログイン後、ホーム・冷蔵庫・AI献立・買い物の右下にある小さな吹き出しをタップ。どの画面から開いたかは自動で記録される。
- 本文だけで投稿できる。画像は1枚まで任意。写真ライブラリから選択、または投稿画面に画像を貼り付けて添付できる。送る前にプレビュー・取り消しができる。
- ホームの「ふたりのご意見メモ」、または投稿画面の「みんなのご意見を見る」から一覧を開く。下部ナビは従来の4タブのまま。
- 一覧では「未対応・検討中・対応済み」を切り替えられる。更新・絞り込み・本文コピー・添付画像の表示・画像だけの削除・メモごとの削除に対応。
- 一覧のチェックを付けたメモをまとめてテキスト出力。未選択なら表示中の状態のメモが対象。50件ずつ読み込み、「続きを読み込む」で対象を増やせる。
- 出力テキストをコピーし、ChatGPTへ手動で貼り付ける。画像・画像の閲覧URLは出力しない。必要なら画像を別に添付する。自動送信・定期監視は行わない。
- クリップボードが使えない環境では、出力欄を全選択して手動コピーする。iPhoneの画像貼り付けはOS・コピー元アプリにより利用できない場合があるため、写真選択も用意している。

## 保存とアクセス制御

本番Supabase `moorgivgwmkbxyjvwuih` を使用。

- `public.feedback_notes`: id、household_id、author_id、author_label、body、source_page、status、image_path、created_at、updated_at。
- RLSですべての操作を既存の `public.is_household_member` に限定。投稿者・投稿者名・作成日時はDB側で自動設定。クライアントは投稿者・世帯・本文・作成日時の改ざん更新ができない。
- 投稿者の表示名は既存アカウントのプロフィール名を優先し、未設定ならメールアドレスの@より前を使用。auth.usersの情報をクライアントで一覧取得する権限は追加しない。
- Storageの `feedback-images` は非公開。オブジェクトキーは `{household_id}/{note_id}/attachment.jpg`。専用RLSで同じ世帯の認証済みユーザーだけがアップロード・読み込み・削除可能。
- 画像は認証付きdownloadでBlobとして取得し、画面内の一時URLで表示。公開URL・署名URLは発行しない。ログアウト・世帯切り替え・一覧更新で一時URLを破棄する。
- 添付時にJPEGへ変換し最大2048pxに縮小。元のEXIFは保存しない。選択元15MBまで、保存後5MBまで。
- 画像の削除はStorage APIを先に実行し、成功後にDBの参照またはメモを削除する。片方が通信エラーなら完了と表示せず、再実行できるようにする。
- 投稿に失敗した場合は本文とプレビューを維持し、アップロード済み画像の後片付けを試みる。通信が途切れて後片付けも失敗した場合はその旨を表示する。
- 世帯切り替え前の遅延応答は表示しない。画像やメモの本文をログ・GitHub・自動ChatGPT連携へ送信しない。
- 一覧を開いたとき、アプリ復帰時、および一覧表示中の20秒間隔で共有先を再読み込みする。

## 検証

- `node --test tests/*.test.mjs`：既存機能とご意見メモのテスト。
- `supabase/tests/feedback-rls.sql`：本番で既存の共有世帯の2アカウントと非メンバーを模したDB権限テスト。作成したテスト行は全てロールバック。Storageの直接DELETEは禁止されているため、画像の実削除はStorage API経由で確認する。
- iPhone実機の写真選択・貼り付け・PWA内のキーボード表示は、端末で最終確認する。
