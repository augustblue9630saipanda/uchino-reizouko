# iPhoneで「うちの暮らし」をホーム画面に追加する

夫婦それぞれのiPhoneで、次の手順を行ってください。

1. **Safari**で [うちの暮らし](https://augustblue9630saipanda.github.io/uchino-reizouko/) を開きます。
2. **共有**（四角から上向きの矢印）をタップします。Safariの表示によっては「…」メニュー内にあります。
3. **ホーム画面に追加**を選びます。見つからない場合は共有メニューを下へスクロールし、「アクションを編集」から追加してください。
4. 名前を **うちの暮らし** にします。**Webアプリとして開く**が表示される場合は、オンにしてください。
5. **追加**をタップし、ホーム画面にできた「u.」と葉のアイコンから開きます。

アイコンから起動するとSafariのアドレスバーがない独立した画面で使えます。時刻・電池などiPhoneのステータスバーは表示されます。

## 最初のログインと共有

ホーム画面のアプリ内でログインを求められたら、**今まで使っている自分のメールアドレスとパスワード**でログインしてください。新規登録は不要です。Safariでログイン済みでも、ホーム画面からの初回起動時にログインが必要な場合があります。

夫婦それぞれの既存アカウントと世帯の共有関係はそのままです。同じ世帯を選ぶと同じ冷蔵庫・買い物リストを使えます。Safariとホーム画面のアプリでログイン状態が異なっても、同じアカウントならサーバー上のデータは共通です。

## アドレスバーが出る・古いアイコンのままの場合

- 必ずホーム画面のアイコンから起動してください。Safariのタブを開いた場合は通常のアドレスバーが表示されます。
- 対応前に追加した古いショートカットの場合は、ホーム画面からそのアイコンを取り除き、Safariで上のURLを再読み込みして追加し直してください。操作対象はホーム画面のアイコンのみです。アプリ内で食材やアカウントを削除する必要はありません。
- 追加後もインターネット接続が必要です。冷蔵庫・買い物リスト・AI献立は今までどおりオンラインで使います。

参考：[Apple公式の追加手順](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)

## 実装メモ

- `manifest.webmanifest` の名前は「うちの暮らし」、displayは`standalone`。
- id/start_url/scopeは既存のGitHub Pages配下`/uchino-reizouko/`に固定。認証情報やユーザー識別子を含めない。
- iOSの互換メタタグと180pxのapple-touch-icon、192px/512pxのPNG、SVGアイコンを設定。アイコンの背景は不透明で、OS側の角丸やマスクに対応する余白を確保。
- `viewport-fit=cover`、動的な画面高、上下左右のセーフエリア、ホームインジケーターを避けるナビ位置を設定。
- Service Worker・通知・追加のデータキャッシュは導入していない。既存のSupabase認証・共有・機能・データは変更していない。
- PNGを作り直す場合：Windows PowerShellで `./scripts/build-pwa-icons.ps1`。
