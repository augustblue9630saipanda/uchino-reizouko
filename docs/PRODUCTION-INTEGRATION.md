## 今回まとめる内容

1. ログイン・家族の招待・参加・冷蔵庫・写真認識は、既存の本番Supabaseを引き続き使います。アカウントの移行や作り直しは不要です。
2. 同じ本番Supabaseに献立専用の `generate-dinner` を1つ追加します。主菜・副菜・汁物を各3案、家族3人分の分量・手順・取り分け・大人向け仕上げを返します。
3. 本番の画面でAI献立のボタンを有効にします。登録済み食材はログインした利用者の権限で読み取ります。食材の自動追加や削除はしません。
4. 今後の環境は公開アプリ＋本番Supabaseの組み合わせを使います。テストプロジェクトのコピーを更新する手順は使いません。

食材データの削除・DB構造変更・アカウントの移行は、この統合には不要です。データを残したまま進めます。
